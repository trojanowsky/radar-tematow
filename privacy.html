Privacy policy – Radar tematow

Last updated: 21 November 2026

What the app is

Radar tematow is a private desktop script used by a single person (the operator) to analyse the operator's own YouTube channels. It is not offered to the public.

What data it accesses

  • With the operator's consent (Google OAuth), read-only access to the operator's own YouTube channels: youtube.readonly and yt-analytics.readonly. This covers the channel's video list, public counters (views, likes, comments) and YouTube Analytics reports (watch time, retention, traffic sources, countries).
  • Public data: YouTube search results and public video statistics, Wikipedia pageview statistics.

The app does not request the email address, profile, contacts or any other Google account data, and it never modifies, uploads or deletes anything on YouTube.

Where data is stored

OAuth tokens and statistics are stored only on the operator's own computer (a local SQLite database and token files). Nothing is sent to any server other than Google's and Wikimedia's APIs, which are called to fetch the data.

Sharing

Data is not sold, shared or transferred to any third party, and is not used for advertising.

Google API Services User Data Policy

Radar tematow's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revoking access

The operator can delete the local data at any time by removing the app's data folder. Access can be revoked at any time at myaccount.google.com/connections, after which the app can no longer read any channel data.

Contact

Questions about this policy: open an issue in the GitHub repository that hosts this page.
