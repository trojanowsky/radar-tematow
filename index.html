Radar tematow

Radar tematow is a private, single-user desktop script. It reads statistics of the operator's own YouTube channels (YouTube Data API and YouTube Analytics API, read-only) and public data (YouTube search results, Wikipedia pageviews) to suggest topics for new videos.

It is not a public service: there is no sign-up, no hosted backend and no data shared with anyone. Data stays on the operator's own computer.
